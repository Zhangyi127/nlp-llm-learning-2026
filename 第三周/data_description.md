# 数据集说明
本数据集为电影评论数据集，一共30条样本，文本来自第二周收集整理的电影评价语句。

数据集一共两列原始字段：
1. comment：电影评论文本，是实验的输入，。
2. label：情感标签，1代表好评；0代表差评。
实验过程衍生得到text_len字段，表示单条评论的字符数量。

数据存在的问题：
1. 文本长度分布不均匀，不同评论字数差距较大。
2. 部分样本虽然标记为好评，但是里面夹杂少量客观缺点描述；部分差评也存在肯定语句。
3. 没有完全空文本，但是个别句子比较简短，包含信息较少。

实验中过滤掉字符长度小于10的样本，得到清洗后的movie_clean.csv，用于后续分析。
